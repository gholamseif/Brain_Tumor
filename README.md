
# 🧠 Brain Tumor MRI Classification using CNN

An AI-powered medical imaging system for brain tumor classification from MRI scans using a Convolutional Neural Network (CNN). The project includes an interactive Streamlit web application that predicts tumor types, visualizes model attention using Grad-CAM, and generates downloadable medical reports.

---

## 📌 Project Overview

This project aims to assist healthcare professionals by classifying brain MRI images into one of four categories:

- 🟢 No Tumor
- 🔴 Glioma
- 🟠 Meningioma
- 🟣 Pituitary Tumor

The system combines Deep Learning with an easy-to-use graphical interface, making AI predictions accessible to non-technical users.

---

## 🚀 Features

- Upload MRI images through an interactive Streamlit interface.
- Automatic brain tumor classification using a CNN model.
- Prediction confidence score.
- Grad-CAM visualization for model explainability.
- Patient information form.
- Automatic medical report generation.
- Download reports in PDF and JSON formats.
- Clean and user-friendly interface.

---

## 🧠 Model

- Deep Learning Model: Convolutional Neural Network (CNN)
- Framework: TensorFlow / Keras
- Task: Multi-Class Image Classification

### Classes

- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

## 📂 Dataset

Brain Tumor MRI Dataset

Source:
https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

The dataset contains labeled MRI images for four different classes used to train and evaluate the CNN model.

## 💡 Explainability

To improve transparency, the system uses Grad-CAM to highlight the regions of the MRI image that influenced the model's prediction.

This helps users better understand how the CNN reached its decision.

---

## ⚠️ Disclaimer

This project is intended for educational and research purposes only.

The predictions generated by the AI model should not be considered a medical diagnosis. Clinical decisions should always be made by qualified healthcare professionals.
